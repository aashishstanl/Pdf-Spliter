📄 CORE FILES (The Framework)
═════════════════════════════════════════════════════════════════════════════════

┌─ work.py (350+ lines)
│  Description: Main PDF processing engine
│  What it does:
│  • Analyzes PDF pages for text markers
│  • Detects "No. X" and "Being No. X" patterns
│  • Splits PDF into individual files
│  • Creates ZIP bundle
│  • Validates all groups
│  Key functions:
│  • process_pdf_file(pdf_path) → Main entry point
│  • analyze_pdf(pdf_path) → Detects groups
│  • create_output_pdfs() → Creates individual PDFs
│  • create_zip_bundle() → Bundles output
│  Usage: from work import process_pdf_file
│         result = process_pdf_file("file.pdf")
│
├─ batch_process.py (200+ lines)
│  Description: Command-line batch processor
│  What it does:
│  • Processes single PDF or entire folder
│  • Generates JSON processing reports
│  • Shows progress and detailed results
│  Usage: python batch_process.py --input "file.pdf"
│         python batch_process.py -i "folder/" -o "report.json"
│
├─ verify_setup.py (250+ lines)
│  Description: Setup verification & troubleshooting
│  What it does:
│  • Checks Python version (3.8+)
│  • Verifies all dependencies installed
│  • Tests Tesseract OCR installation
│  • Checks output directory permissions
│  • Provides installation guidance
│  Usage: python verify_setup.py
│
├─ config.py (50+ lines)
│  Description: Configuration file
│  What to edit:
│  • OUTPUT_BASE_DIR = where files are saved
│  • DPI = OCR quality (higher = better but slower)
│  • DEBUG = enable/disable logging
│  • MAX_PDF_SIZE_MB = file size limit
│  Usage: Edit directly, then run framework
│
└─ requirements.txt (4 lines)
   Description: Python package dependencies
   Includes: PyPDF2, pdf2image, pytesseract, Pillow
   Usage: pip install -r requirements.txt

🆘 QUICK TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

Problem                         Solution
────────────────────────────    ──────────────────────────
Tesseract not found             Install from GitHub
Poor text detection             Increase DPI in config.py
No PDFs created                 Check for "No. X" markers
Memory error                     Lower DPI or process smaller files
Markers not detected            Ensure text is clearly visible
File too large (> 5MB)          Pages may not be split correctly
