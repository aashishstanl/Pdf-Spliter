✅ PROCESSING RULES (Implemented)
═══════════════════════════════════════════════════════════════════════════════

1. START OF FILE
   ✓ Detected by: "No. X" at top/left margin
   ✓ Defines file name: X.pdf

2. END OF FILE
   ✓ Detected by: "Being No. X" blue stamp
   ✓ Must match the number from start

3. IMMEDIATE STOP (New section before end)
   ✓ If "No. Y" found before "Being No. X"
   ✓ Previous file ends before this page
   ✓ New file starts from this page

4. NEXT FILE START
   ✓ If "No. Y" appears: start new file
   ✓ If no "No.": continue until marker or fallback

5. FALLBACK NAMING (When no "No." at top)
   ✓ Use blue stamp 5th line number
   ✓ Becomes file name

6. INCLUSION RULES
   ✓ Include start page
   ✓ Include "Being No." page
   ✓ Exclude pages from next group

7. VALIDATION
   ✓ First page has "No. X"
   ✓ Last page has "Being No. X"
   ✓ No page overlaps
   ✓ Files < 5MB each
   ✓ Bundled to ZIP


🛠 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: "pytesseract.TesseractNotFoundError"
Solution: Install Tesseract or set path in verify_setup.py output

Problem: Poor OCR recognition
Solution: Increase DPI in config.py (DPI = 600)

Problem: Text detection failing
Solution: Ensure markers are clearly visible and not rotated

Problem: Memory error with large PDFs
Solution: Lower DPI setting or process in smaller batches

Problem: No PDF files created
Solution: Check PDF has "No. X" and "Being No. X" markers
